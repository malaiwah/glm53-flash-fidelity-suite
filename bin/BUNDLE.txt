# Files the cloud runner uploads to the instance.
#
# This list is the upload set. It exists so that what lands on rented hardware
# is auditable and reviewable, rather than "whatever happened to be in the
# directory" -- which is how a stray note, a scratch receipt, or somebody's
# token file ends up on somebody else's machine.
#
# One path per line, relative to the suite root. Missing files are skipped
# (the controller logs which), so a lane whose engine is not present in this
# checkout does not break the upload.
#
# Nothing under .secrets/ is ever listed here. The HF token is transported
# separately, as a 0600 file, and shredded during teardown.
